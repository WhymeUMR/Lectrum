# Step 06 Quality Rubric

Рубрика применяется к выборке сгенерированных флешкарт перед релизом.

## Критерии

1. Faithfulness (0-2)
   - 0: ответ не связан с транскриптом
   - 1: частично связан, есть неточности
   - 2: корректно отражает факты из транскрипта
2. Clarity (0-2)
   - 0: вопрос/ответ нечитаемы
   - 1: формулировки понятны частично
   - 2: вопрос и ответ короткие и однозначные
3. Learning Value (0-2)
   - 0: карточка бесполезна для запоминания
   - 1: есть ценность, но слабая проверка понимания
   - 2: карточка проверяет ключевую концепцию
4. Format Compliance (0-2)
   - 0: нарушение обязательных полей схемы
   - 1: схема валидна, но есть шум (лишние/пустые hints/tags)
   - 2: полное соответствие схеме и ограничениям

## Порог качества

- Карточка считается приемлемой при сумме >= 6/8.
- Набор считается приемлемым, если:
  - не менее 90% карточек в выборке имеют >= 6/8;
  - средний балл по выборке >= 6.5/8.

## Процедура проверки

1. Берем минимум 40 запусков генерации.
2. Валидируем JSON по `FlashcardDeckSchema`.
3. Прогоняем автоматическую метрику шага 6 (`scripts/verify-step6.mjs`).
4. Для случайных 20 карточек делаем ручной аудит по рубрике выше.
