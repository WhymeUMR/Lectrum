# Lectrum

Lectrum — это платформа для обучения по лекциям и материалам: она принимает исходный контент (файл, ссылку на страницу или видео), обрабатывает его и превращает в удобные учебные форматы.

## Что умеет проект
- загружать и обрабатывать учебные материалы;
- строить транскрипты лекций;
- выделять ключевые моменты и делать summary;
- генерировать flashcards и тесты;
- давать возможность общаться с ассистентом по содержанию лекции;
- озвучивать пересказ через TTS.

## Как это работает
Внутри используется микросервисный pipeline: API принимает запрос, фоновые сервисы обрабатывают материал через очереди, а результат сохраняется в БД и артефактах. Пользователь получает прогресс задачи и готовые результаты через API.

## Для кого проект
Lectrum ориентирован на студентов, преподавателей и команды, которым нужно быстро превращать «сырые» лекционные материалы в структурированный учебный контент.
